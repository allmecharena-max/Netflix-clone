# 🎬 Netflix UI Clone

A modern, pixel-perfect clone of the Netflix user interface built entirely with semantic HTML5 and responsive CSS3. Developed as an educational project to master modern web layout techniques and UI design patterns

---

## ✨ Features

- **Pixel-Perfect Accuracy:** Closely mirrors the authentic Netflix typography, color scheme, and layout constraints.
- **Modern UI Components:** Includes a high-impact hero banner, horizontal scrolling movie rows, and custom button styling.
- **Fully Responsive:** Adapts to desktop, tablet, and mobile screens using modern CSS layout systems.
- **Micro-interactions:** Smooth hover states, scaling card effects, and transition animations that mimic the premium streaming experience.

---

## 🛠️ Built With

This project is built purely with native web technologies to demonstrate core front-end layout competencies without relying on heavy frameworks:

- **HTML5:** Structured using clean, semantic tags (`<nav>`, `<header>`, `<main>`, `<section>`, `<footer\>`) for optimal SEO and accessibility.
- **CSS3:** Built using advanced styling methodologies:
  - **CSS Flexbox & Grid:** Used for alignment, navigation layouts, and dynamic, multi-column movie rows.
  - **Custom Properties (Variables):** Standardized color palettes and spacing tokens for global consistency.
  - **Media Queries:** Tailored breakpoints ensuring a seamless experience across all device form factors.
